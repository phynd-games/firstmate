{# Theme override for the Firstmate document reader (bin/fm-docs-reader.sh copies this directory into state/docs-reader/theme and points MkDocs' custom_dir at it). It extends the bundled `mkdocs` theme and replaces only its navigation and page layout: - The bundled theme renders every first-level navigation entry into one horizontal navbar with dropdowns. A Firstmate home has one directory per task under data/, so that navbar grows with the task count until it is taller than the viewport and, being sticky, covers every document. The section tree below renders the same nav as a vertical, independently scrolling panel: inline beside the document on wide viewports, a Bootstrap offcanvas dialog behind a "Documents" button on narrow ones (which is what 200% browser zoom produces). Native
elements give each section a keyboard-operable disclosure with no script. - The document sits in a bounded reading column with an "On this page" outline; css/reader.css owns the measure, type scale, and spacing. - The bundled darkmode.js expects #hljs-light/#hljs-dark stylesheet links that only exist when the remote highlight.js is enabled; with it disabled the script threw before wiring the theme toggle. The two generated local Pygments stylesheets below fill those ids, so the toggle works and code keeps readable colours in dark mode. Everything referenced here is served from the reader itself; nothing is fetched from the network.
